# 人民币汇率显示应用 - 产品需求文档 (PRD)

## 1. 背景

随着全球化贸易和跨境交流的日益频繁，个人和企业对汇率信息的需求越来越迫切。当前市场上虽有不少汇率工具，但存在数据更新不及时、界面复杂、加载缓慢等问题。用户需要一个**快速、直观、实时**的汇率查看工具来辅助日常的外汇决策。

本次产品升级将扩大货币覆盖范围至 **20+ 币种**，并支持**双向汇率显示模式**，满足不同用户的查看习惯。

## 2. 目标

开发一款基于 Streamlit 的人民币汇率展示应用，实现以下目标：
- **多币种支持**: 实时展示人民币对 20+ 种主要外币的当前汇率
- **灵活显示**: 支持「1 RMB = ? 外币」和「1 外币 = ? RMB」两种显示模式
- **趋势分析**: 可视化呈现24小时汇率变化趋势（涨跌幅、涨跌额）
- **交互友好**: 提供手动刷新功能，界面简洁美观
- **状态完善**: 错误处理和加载状态完善

## 3. 功能列表

### 3.1 货币选择模块
| 功能点 | 描述 |
|--------|------|
| 货币下拉选择 | 用户可通过多选下拉框选择要查看的货币种类 |
| 预设快捷选项 | 提供「热门货币」「亚洲货币」「全球货币」等快捷选择 |
| 币种数量 | 支持至少 **25 种** 国际货币 |
| 币种列表 | 美元、欧元、英镑、日元、港币、台币、新加坡元、韩元、泰铢、马来西亚林吉特、印尼盾、越南盾、菲律宾比索、瑞士法郎、澳元、新西兰元、加元、印度卢比、俄罗斯卢布、阿联酋迪拉姆、沙特里亚尔、墨西哥比索、土耳其里拉、巴西雷亚尔 |

### 3.2 显示模式模块
| 功能点 | 描述 |
|--------|------|
| RMB转外币模式 | 显示「1 RMB = ? 外币」汇率 |
| 外币转RMB模式 | 显示「1 外币 = ? RMB」汇率 |
| 模式切换 | 通过单选按钮或下拉框切换显示模式 |
| 汇率换算 | 两种模式自动换算，数值互为倒数 |

### 3.3 汇率展示模块
| 功能点 | 描述 |
|--------|------|
| 汇率卡片 | 每个货币对以卡片形式展示当前汇率 |
| 涨跌标识 | 通过颜色（绿色=涨，红色=跌）和箭头标识涨跌状态 |
| 数值格式 | 根据货币种类自动格式化（小数位数） |

### 3.4 趋势展示模块
| 功能点 | 描述 |
|--------|------|
| 涨跌幅显示 | 展示24小时涨跌幅百分比 |
| 涨跌额显示 | 展示24小时涨跌金额 |
| 趋势图表 | 使用折线图展示24小时汇率走势 |

### 3.5 交互功能模块
| 功能点 | 描述 |
|--------|------|
| 手动刷新 | 提供刷新按钮，支持即时获取最新汇率数据 |
| 自动刷新 | 页面启动时自动加载一次数据 |
| 时间戳显示 | 显示数据更新时间 |

### 3.6 状态处理模块
| 功能点 | 描述 |
|--------|------|
| 加载状态 | 数据加载时显示 loading spinner |
| 错误处理 | API 调用失败时显示友好错误提示 |
| 空数据处理 | 数据为空时给出明确提示 |

## 4. 非功能需求

| 类型 | 要求 |
|------|------|
| **性能** | 页面首次加载 < 3秒，刷新操作 < 2秒 |
| **稳定性** | API 超时设置 10 秒，超过后显示错误而非无限等待 |
| **兼容性** | 支持主流浏览器（Chrome、Firefox、Safari、Edge） |
| **维护性** | 汇率 API 地址可配置，便于后续更换数据源 |
| **扩展性** | 货币配置与代码分离，易于新增币种 |

## 5. 验收标准

### 5.1 功能验收
- [ ] 页面启动后自动加载并显示用户选择的货币汇率
- [ ] 支持至少 25 种货币的多选
- [ ] 「1 RMB = ? 外币」和「1 外币 = ? RMB」模式可正常切换
- [ ] 每个货币卡片显示：货币对名称、当前汇率、涨跌幅、涨跌额
- [ ] 点击刷新按钮后数据更新，且更新时间戳刷新
- [ ] API 调用失败时页面显示错误信息而非崩溃
- [ ] 数据加载过程中显示加载指示器

### 5.2 界面验收
- [ ] 整体布局为卡片式，货币对横向排列
- [ ] 涨幅用绿色背景/文字标识
- [ ] 跌幅用红色背景/文字标识
- [ ] 趋势图清晰可读，坐标轴标注完整
- [ ] 显示模式切换按钮位置明显

### 5.3 技术验收
- [ ] 使用 Streamlit 框架实现
- [ ] 无 Python 语法错误
- [ ] 可通过 `streamlit run app.py` 直接运行

## 6. 技术方案

### 6.1 技术栈
- **框架**: Streamlit
- **数据可视化**: Plotly
- **HTTP 请求**: Requests
- **数据源**: 免费汇率 API (exchangerate-api.com 或 similar)

### 6.2 目录结构
```
exchange_rate_app/
├── app.py              # 主应用文件
├── config.py           # 货币配置（币种列表、符号等）
├── requirements.txt    # 依赖清单
└── README.md           # 使用说明
```

### 6.3 货币配置结构
```python
CURRENCY_CONFIG = {
    "USD": {"name": "美元", "symbol": "$", "flag": "🇺🇸", "decimal": 4},
    "EUR": {"name": "欧元", "symbol": "€", "flag": "🇪🇺", "decimal": 4},
    # ... 25+ 币种
}
```

### 6.4 显示模式换算逻辑
```
模式 A (1 RMB = X 外币):
    rate_A = base_rate  # API 直接返回的汇率

模式 B (1 外币 = X RMB):
    rate_B = 1 / base_rate
```

### 6.5 API 设计
使用免费汇率 API，每小时请求量有限制，应用需做好缓存和错误处理。
