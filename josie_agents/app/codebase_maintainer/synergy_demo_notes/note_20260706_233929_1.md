## 🥇 第一优先级（立即处理 - P0）

### 1. models.py:66 - Order.calculate_total 计算逻辑
**理由**：当前实现会直接导致订单金额计算错误
```python
def calculate_total(self) -> float:
    # TODO: 考虑折扣和税费
    return sum(p.price for p in self.products)  # ❌ 忽略折扣和税费
```
**建议**：
- 引入 `Order` 级别的 discount 字段
- 添加 tax_rate 字段
- 计算公式：subtotal * (1 - discount) * (1 + tax_rate)

### 2. models.py:50 - Product.apply_discount 验证
**理由**：缺少边界检查，可能产生负价格或异常结果
```python
def apply_discount(self, percentage: float) -> float:
    # TODO: 添加折扣验证
    return self.price * (1 - percentage / 100)  # ❌ 无边界检查
```
**建议**：验证 0 <= percentage <= 100

### 3. api_client.py:41 - 添加重试逻辑
**理由**：网络波动时请求必然失败，影响系统可用性
**建议**：使用 `tenacity` 或 `urllib3.Retry`，配置指数退避
