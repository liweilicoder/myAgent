# P0 整改行动计划

## 目标
消除最严重的健壮性与业务正确性风险,在生产化前必须完成。

## 任务清单(按依赖顺序)

### T1. requirements.txt
- 内容: requests>=2.31.0,<3.0.0 | pandas>=2.0.0,<3.0.0
- 验收: pip install -r requirements.txt 可成功,且版本固定

### T2. APIClient 加超时与重试
- 改动点:
  - __init__ 增加 timeout=10, max_retries=3 参数
  - 使用 urllib3.util.Retry + HTTPAdapter 挂载到 session
  - 指数退避 backoff_factor=0.5
- 验收: 模拟 503/超时,确认自动重试;关闭 TODO:41

### T3. utils.load_config 异常处理
- 改动点:
  - FileNotFoundError → 返回 {} (或抛 ConfigNotFoundError,由调用方决定)
  - JSONDecodeError → 抛 ConfigFormatError,带文件路径
  - PermissionError → 抛 ConfigPermissionError
- 验收: 删除文件/损坏 JSON/无权限 三场景测试通过

### T4. Product.apply_discount 范围校验
- 改动点: percentage < 0 或 > 100 抛 ValueError
- 验收: assertRaises 测试通过;关闭 TODO:50

### T5. Order.calculate_total 完成 TODO
- 改动点:
  - 接受可选 discount_rate, tax_rate 参数
  - 折扣后小计 * (1 + tax_rate)
  - 校验 discount_rate/tax_rate 范围同 T4
- 验收: 单元测试覆盖正常/折扣/含税场景;关闭 TODO:66

### T6. 移除 utils.format_size 副作用
- 改动点: 局部变量 size = float(size_bytes),不修改入参
- 验证: 类型契约保持一致;原有测试不破坏

## 依赖关系
T1 独立 → T2 依赖 requests(从 T1 来) → T3 独立 → T4 独立 → T5 独立 → T6 独立
