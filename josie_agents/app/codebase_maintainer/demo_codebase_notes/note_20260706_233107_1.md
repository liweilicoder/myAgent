# data_processor.py 代码设计分析

## 模块定位
flask_app 包内的数据处理层（63 行，5 个函数），基于 pandas 的函数式管道。

## 设计模式
Façade + Pipeline:
- process_data: 顶层入口 (list[dict] → DataFrame → clean → transform)
- clean_data: dropna + drop_duplicates
- transform_data: 新增 processed_date 列（基于 date 列）
- aggregate_data: groupby + sum/mean/count on value
- export_data: 写 CSV

## 主要问题
1. 硬编码列名 'date'/'value' (schema 耦合)
2. 无错误处理与日志 (print 而非 logger)
3. dropna() 默认 how='any'，过度清洗
4. aggregate_data 未 reset_index，返回 MultiIndex 列
5. to_datetime 不带 errors='coerce'，脏日期崩溃
6. 与 models.py 完全脱节，无 schema 联动

## 改进优先级
P0: 配置化 schema 参数化、错误处理、logger
P1: 与 models.py 联动、清洗策略细化
P2: aggregate 输出标准化、export 支持多格式
P3: 单测覆盖（tests/test_data_processor.py）
